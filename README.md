# 加密货币研究 / Crypto Research Notes

静态站点，线上 [coin.ponr.org](https://coin.ponr.org)。中英双语核验型长文：研究方法、链上数据、稳定币与跨链、协议与治理风险。内容仅供学习研究，不构成投资建议。

This is a hand-written static site (no SSG). Chinese pages live at the repo root; English mirrors under `/en/`.
